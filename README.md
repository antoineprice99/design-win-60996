## About Digital Insurance Infographic Maker

Digital Insurance Infographic Maker is a browser-based infographic tool built for creating structured, on-brand visual boards for digital insurance content. It runs as a single-file HTML experience, so it can be opened directly in the browser and used without a traditional installed app.

The tool is designed for local browser-only rendering, which keeps editing within the page itself and supports offline use in the baked-in version. It is a practical fit for teams or individuals who need a lightweight way to assemble infographic layouts, review board variations, and export finished visuals as PNG images.
